Projects

Navidrome

Python, pytest, requests, Playwright, Docker Compose

Navidrome is an open-source music server, so this is testing from the outside: all I had was the running app and its API. The suite starts a throwaway server, fills it with generated audio, then runs more than forty API and browser tests against it.

What the tests found

  • Confirmed, fix in review

    Adding tracks to a playlist counted track IDs that don't exist as added. The maintainer confirmed it and opened a fix, which I verified against the patched build. Read the issue

  • Documented

    The API creates playlists with no name, which the web form forbids.

Game Library

FastAPI, SQLite, pytest, Playwright in TypeScript

A small game tracker built to be tested, with a written spec and four bugs planted in it, unmarked. Because the app's code is in the repository, it is tested at three levels: more than eighty unit tests on the rules, API tests that run the app in-process, and more than fifty browser tests.

What the tests found

  • Planted, found

    A title of exactly 100 characters is rejected, though the limit is 100. An off-by-one at the boundary.

  • Planted, found

    The duplicate check misses the same title in a different letter case.

  • Planted, found

    After cancelling an edit, adding a new game overwrites the game that was being edited.

  • Planted, found

    The count under the list shows the games on the page, not the total.

Background

I don't have a computer science degree. I taught myself testing the way I'd want any tester to learn it: pick real software, try to break it, and write down exactly what happened.

The repository is the record of that. It started as a few scripts and grew one step at a time, and the commit history shows each step.

  1. Plain Python scripts that called an API and printed what came back.
  2. A pytest suite, with fixtures and assertions that can actually fail.
  3. Browser tests with Playwright and page objects.
  4. A test server in Docker Compose, and every suite running in GitHub Actions.
  5. A bug found in Navidrome and reported upstream.
  6. An app with planted bugs, tested at unit, API and browser level.
  7. This site, with tests of its own.
